# Heroes of Sardath

A two-player co-op fantasy adventure for the browser. George the Wizard and Rory the Moonfox take turns on the same screen: dice duels in the style of the Fighting Fantasy books, treasure, tricky choices and a siege battle in each chapter.

**Play it:** https://omniwolf.github.io/heroes-of-sardath/

The whole game is one file, `index.html`. You can also download it and double-click it to play offline.
